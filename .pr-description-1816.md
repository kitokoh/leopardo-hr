## Description

**Closes #1816** — [F-20][DZ] actual_days_worked depuis les logs de présence réels — AttendanceLog → PayrollCalculator

Branche le décompte des jours réellement pointés dans la paie : `actual_days_worked` reflète désormais le nombre de jours DISTINCTS avec au moins un log `AttendanceLog` valide sur la période du run, au lieu du seul prorata calendaire.

### Changements

- **`PayrollCalculator::computeWorkedDays()`** : compte les jours distincts pointés (statuts `cancelled`/`rejected`/`incomplete` exclus, scoped `company_id` + `employee_id` + période) ; **fallback** = prorata contrat (comportement historique) quand aucun log valide n'existe. Nouvelle clé `has_attendance_data` dans le retour. Garde défensive `Schema::hasTable('attendance_logs')` pour les environnements sans schéma tenant (golden tests purs).
- **Migration tenant additive idempotente** : `pay_slips.has_attendance_data BOOLEAN DEFAULT false` (résolution multi-schéma via `resolveTableSchema`/`schemaHasColumn`).
- **`calculateSlip()`** : stocke `has_attendance_data` sur le `PaySlip` à la création (auditabilité de la source du décompte). Modèle `PaySlip` : fillable + cast boolean + docblock.
- **Docs** : `docs/payroll/DZ_COMPLIANCE.md` §5 — source des jours travaillés (AttendanceLog si disponible, prorata contrat sinon).

### Tests

- `PayrollWorkInputsTest` : 18 logs valides → `actual_days_worked = 18.0` + `has_attendance_data = true` ; statuts invalides (cancelled/rejected/incomplete) + doublons même jour + log hors période exclus ; fallback 0 log → prorata 22.0 + `has_attendance_data = false`.
- `GoldenDzProrataOvertimeTest` : 2 cas golden DB-backed (#1816) — 18 logs → 18,0 ; 0 log → 22,0 — la classe passe sous `RefreshTenantDatabase` (déjà le cas de `GoldenDzEndOfContractRulesTest`/`GoldenDzLeaveIndemnityRealDataTest`).
- `PayrollTenantIsolationTest` : les logs d'un autre tenant ne sont pas comptés (fallback conservé).
- Vérifié localement : suites ci-dessus vertes + `PayrollCalculatorCoverageTest`/`PayrollCalculatorRunEdgeTest` (régression prorata) verts, **PHPStan strict 0 erreur**, Pint PASS.

### Hors périmètre (conforme issue)
