# DocKeeper Learnings

- **Broken Links Detection**: Root `README.md` often lags behind document renames or archiving. Always verify entry points against the actual file system.
- **Version Synchronization**: `PROGRAM_VERSION` must be updated in `PILOTAGE.md`, `CHANGELOG.md`, and `api/config/app.php` simultaneously to maintain project integrity.
- **Root Cleanup**: Consolidating multiple "Entry Points" sections in `README.md` into a single coherent list improves onboarding and clarity for both humans and agents.
