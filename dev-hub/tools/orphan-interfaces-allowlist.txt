# orphan-interfaces-allowlist.txt — interfaces de contrat DDD sans implementation
# (issue #1492, ADR GOV-001).
#
# Regles identiques aux autres listes d'exclusion du depot
# (actions-convention-allowlist.txt, openapi-coverage) :
#   - une entree = un NOM D'INTERFACE (sans namespace, sans chemin) ;
#   - toute interface orpheline ABSENTE de cette liste est bloquante ;
#   - une entree dont l'interface est desormais implementee DOIT etre purgee
#     (anti-regression : le garde echoue aussi sur une entree orpheline) ;
#   - ne JAMAIS ajouter une entree ici sans justification ecrite : c'est la
#     seule tolerance du garde.
#
# ═══════════════════════════════════════════════════════════════════════════
# ETAT : VIDE — 0 orphelin au 2026-10-23.
# ═══════════════════════════════════════════════════════════════════════════
#
# Aucune interface de contrat du depot n'est sans implementation. Le garde
# `check-orphan-interfaces.sh` est donc BLOQUANT (workflow
# route-owner-and-orphan-interfaces-guard.yml, #8832) : toute nouvelle
# interface orpheline fera echouer la CI.
#
# Historique des entrees purgees (ne PAS les reintroduire) :
#
#   Categorie C — 14 contrats « contract-first » jamais consommes
#     SUPPRIMES le 2026-10-23. Aucun usage hors de leur propre fichier
#     (ni implements, ni bind, ni injection, ni test, ni seeder, ni route).
#     Ils ne protegeaient donc rien. Liste complete dans l'ADR GOV-001.
#
#   Categorie A — GeofenceValidatorInterface
#     RESOLUE le 2026-10-23 par IMPLEMENTATION, pas par suppression :
#     `AttendanceGeofenceService implements GeofenceValidatorInterface`.
#     Le contrat etait BINDE dans AttendanceServiceProvider sans qu'aucune
#     classe ne l'implemente — un binding qui se resolvait sans erreur tout
#     en ne produisant jamais un objet conforme au type declare. C'etait le
#     seul cas de la liste qui soit un vrai defaut, pas une dette
#     d'abstraction. `evaluate()` avait deja la signature exacte du contrat.
#
#   Categorie B — AccessTokenServiceInterface, CameraRepositoryInterface
#     SUPPRIMEES le 2026-10-23 (docs/adr/GOV-001-interfaces-orphelines.md).
#     Aucune implementation, aucun binding, aucun consommateur.
#     `AccessTokenServiceInterface` decrivait en outre un modele de jeton que
#     le service reel (`CameraStreamTokenService`, JWT HS256) n'a jamais
#     utilise : le realigner aurait « presque » marche tout en decrivant une
#     autre conception. Si l'abstraction redevient necessaire, elle doit etre
#     ecrite A PARTIR de `CameraStreamTokenService::issue()`.
#
# Sortie de dette documentee :
