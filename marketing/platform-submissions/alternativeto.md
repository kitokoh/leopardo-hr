# AlternativeTo — Leopardo RH

## Fiche prête à saisir

**Application name**  
Leopardo RH

**Official website**  
À remplacer par l’URL canonique stable avant soumission. En attendant, utiliser le dépôt : https://github.com/kitokoh/leopardo-hr

**Description**  
Leopardo RH is an open-source, mobile-first HR and payroll operating system for growing and field-based companies. It centralizes employee records, attendance, leave, schedules, documents, payroll preparation and workforce analytics across web, mobile and biometric kiosk interfaces.

**Description française**  
Leopardo RH est un système RH et paie open source, mobile-first et multi-tenant pour les entreprises en croissance. Il centralise les dossiers employés, les présences, les absences, les horaires, les documents, la préparation de paie et les analyses workforce sur web, mobile et kiosque biométrique.

**License**  
MIT

**Platforms**  
Web, Android, iPhone/iPad ou mobile selon les applications effectivement publiées ; self-hosted / on-premise pour l’instance serveur.

**Tags suggérés**  
Human Resources, HRM, HRIS, Payroll, Employee Management, Attendance Management, Time Tracking, Workforce Management, Open Source, Self-Hosted, Employee Scheduling, Business Intelligence, Mobile App, Multi-Tenant.

**Pricing**  
Open source / free to self-host. Une offre SaaS peut être indiquée séparément uniquement si une page tarifaire publique et stable existe.

**Alternatives à associer avec prudence**  
Odoo, OrangeHRM, ERPNext, Sentrifugo, Factorial, BambooHR et Zoho People peuvent servir de points de comparaison, sans prétendre que Leopardo RH reproduit toute leur couverture fonctionnelle.

## Procédure

AlternativeTo indique qu’il faut créer un compte, vérifier l’adresse e-mail, choisir « Suggest new application », puis renseigner les plateformes, la licence, les descriptions et les tags avant l’envoi en revue [1]. La soumission est préparée mais non publiée.

## Points de contrôle

Ne pas présenter `leopardo-rh.com` comme URL active tant que le problème DNS signalé dans le README n’est pas résolu. Ne pas utiliser « certified ISO 27001 » : le dépôt parle d’une architecture « ISO 27001-ready », ce qui n’est pas une certification.
