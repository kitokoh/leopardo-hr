# SourceForge — Leopardo RH

## Fiche de projet proposée

**Project name**  
Leopardo RH

**Short description**  
Open-source HR and payroll operating system for growing field-based companies.

**Full description**  
Leopardo RH is a modular, open-source HR and payroll platform for organizations that need to manage employees, attendance, schedules, leave, documents and payroll preparation across multiple sites. It provides web dashboards, Flutter mobile applications, biometric kiosk workflows and an OpenAPI integration layer. The project is MIT licensed and can be self-hosted with PostgreSQL and Redis.

**Project URL**  
https://github.com/kitokoh/leopardo-hr

**License**  
MIT

**Primary technologies**  
PHP 8.4, Laravel 12, PostgreSQL 16, Redis 7, Next.js 16, React 19, Vue 3, Flutter and Dart 3.

**Suggested categories**  
Human Resources, Payroll, Business Management, Office / Business, Internet, Mobile.

**Audience**  
HR teams, operations managers, developers, accounting partners and organizations seeking an open-source or self-hosted HR platform.

**Release / distribution policy**  
Use GitHub Releases as the canonical source until a tested SourceForge distribution workflow exists. Do not mirror private configuration, demo credentials or unverified production builds.

## Décision recommandée

SourceForge présente des fonctions de miroir, de téléchargement, de suivi des tendances, de tickets, de wiki, de forums et d’hébergement pour les projets open source [1]. Cette présence peut accroître la découvrabilité développeur, mais elle crée aussi une seconde surface de distribution et de support. Créer le projet seulement lorsque l’équipe peut maintenir les releases, la documentation et les tickets sur deux plateformes.
