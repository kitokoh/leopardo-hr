**Short Description**  
An AI-native, mobile-first HR and Payroll operating system for growing companies.

**Long Description**  
Leopardo RH is a modular, open-source HRIS platform built with PHP 8.4, Laravel 12, and Flutter. It is designed to handle the complexities of field-based workforce management, including biometric attendance (ZKTeco), multi-country payroll compliance, and multi-tenant data isolation. The project emphasizes transparency, security, and extensibility, providing a robust alternative to closed-source enterprise HR suites.

**Technical Highlights**  
- **Backend:** Laravel 12, PostgreSQL 16, Redis 7.
- **Frontend:** Next.js 16, Vue 3.
- **Mobile:** Flutter / Dart 3 (5 native apps).
- **Architecture:** Modular Monolith with Domain-Driven Design (DDD).
- **Integrations:** Full OpenAPI 3.0 specification.
