### #4393 — Metadata `<title>`/description FR en dur quand la locale vient d'Accept-Language (P2, web)

mais `<title>Documentation API | Guides techniques Leopardo RH</title>` FR. ~15 pages
impactées. Cause racine : `middleware.ts` ne copie que `?lang=` vers `x-vitrine-lang`
(#4004) ; les ~20 layouts landing n'ont pas le fallback Accept-Language du root
layout (#2657). `/pricing` était le seul layout correct (#3487). Issue créée + fix.

`/platform/plans`, `/demo-users`, `/onboarding/invitation/*`, `/trial/signup`
(#3259/#3879) — tandis que les endpoints non throttlés répondent 200
(`/supported-countries`, `/i18n/catalog/*`). Cause probable : `CACHE_STORE=redis`
+ instance Render `leopardo-redis` (#3774) injoignable (env REDIS_URL/REDIS_PASSWORD).
Diagnostic complet commenté sur #4370. Explique aussi #2646.

## Leçons

1. **Secondary rate limit GitHub partagé** : avec un swarm qui hammer le même token,
   l'API REST est indisponible par intermittence (403 « rate limit exceeded » malgré
   4900/5000 restants). Workaround : travailler en local (git protocol fonctionne :
   push/delete branches OK), batcher les appels API, retry avec backoff, et ne jamais
   bloquer dessus.
2. **Toujours re-fetcher avant d'agir** : le swarm crée/merges des branches en continu
   (fix/4185, 4206-lot3/4, 4290-4390 apparus pendant la session). Vérifier `mergeable_state`
   et le contenu (sha) avant merge — plusieurs PRs « ouvertes » étaient en réalité déjà
   mergées (contenu identique sur main).
3. **Les guards locaux sont exécutables sans PHP/Docker** : `dev-hub/tools/*.sh` (bash)
   et `*.js` (node) valident domaines, env-parity, pays, formats mobiles, i18n diff —
   à lancer sur chaque branche avant push.
4. **L'audit runtime prod (curl) bat l'audit statique** pour les findings SEO/i18n :
   le bug metadata (FR titles avec Accept-Language) n'était visible qu'en testant le
   serveur réel, pas dans le code (le code semblait correct avec ?lang=).
