- [`docs/REFERENTIEL_PRODUIT/APV.md`](../REFERENTIEL_PRODUIT/APV.md) - Manifeste 1 page (4 piliers + 12 Lois)
- [`docs/REFERENTIEL_PRODUIT/ROADMAP.md`](../REFERENTIEL_PRODUIT/ROADMAP.md) - Phasage MVP -> modules a la demande
- [`docs/REFERENTIEL_PRODUIT/STATUTS.md`](../REFERENTIEL_PRODUIT/STATUTS.md) et [`docs/REFERENTIEL_PRODUIT/COULEURS.md`](../REFERENTIEL_PRODUIT/COULEURS.md) - Tokens design partages Flutter <-> Tailwind
