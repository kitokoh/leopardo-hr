# Plan 59 - Requalification strategique du produit

## Source

Point utilisateur 33.

## Objectif

Clarifier le positionnement de Leopardo RH : HRMS, Workforce OS, Company OS mobile-first ou autre. Produire une recommandation exploitable pour vitrine, pitch, pricing, docs et roadmap.

## Hypothese de depart

Le produit depasse deja une simple application RH : RH, pointage, taches, validation, documents, notifications, suivi activite, performance, paie simplifiee, kiosque et onboarding.

## Lots d'execution

### Lot 59.1 - Analyse produit

- Cartographier les modules reels deja implementes.
- Separateur : module vendu maintenant, module beta, module roadmap.
- Identifier proposition de valeur principale par persona : employe, manager, RH, direction, super-admin.

### Lot 59.2 - Analyse marche

- Comparer categories : HRMS, Workforce Management, Field Workforce, Company OS, Mobile Enterprise OS.
- Positionner concurrents : BambooHR, Factorial, Rippling, ERPNext/Frappe HR, Odoo HR, Deel, Deputy, Connecteam.
- Identifier differenciation Afrique/Maghreb/mobile/kiosque/paiement terrain.

### Lot 59.3 - Recommandation branding

- Proposer 3 formulations :
  - Prudente : "Plateforme RH mobile-first".
  - Ambitieuse : "Workforce OS mobile-first".
  - Vision long terme : "OS de gestion d'entreprise mobile-first".
- Choisir formulation par page : vitrine, docs developpeur, investor pitch.

### Lot 59.4 - Mise a jour vitrine

- Adapter hero, pricing, pages ressources et metadata.
- Eviter de promettre les modules non encore production-ready.

## Livrables

- Document strategie produit.
- Copywriting vitrine.
- Matrice promesses vs modules reels.

## Criteres d'acceptation

- Le positionnement est clair, vendable et defendable techniquement.
- La vitrine ne survend pas les modules encore incomplets.
- Les prochains plans produit suivent ce positionnement.
