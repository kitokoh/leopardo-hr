# Plateformes de référencement

> Où inscrire la solution pour gagner en visibilité organique. Chaque ligne porte son état :
> **fait** (fiche rédigée) · **à faire** (décidée) · **publié** (en ligne, avec URL).
>
> Les kits de soumission détaillés (champs exacts, captures, prérequis) sont dans
> `docs/GOTO_MARKET/platform-submissions/`. Les UTM canoniques sont dans
> `docs/GOTO_MARKET/CONVENTION_UTM.md`.
>
> **Règle** : une ligne n'est `publié` que si la colonne URL est remplie.

## Priorité de publication

1. **GitHub** — la fiche est la destination de tous les autres liens ; elle doit être propre
   avant toute campagne.
2. **Annuaires open source** — coût faible, trafic qualifié, durée de vie longue.
3. **Listings B2B** — demandent des avis clients réels ; ne pas publier avant d'avoir des
   utilisateurs qui peuvent témoigner.
4. **Product Hunt / HN** — one-shot ; à réserver au moment où la vitrine est stable.
