## 3. 🟠 Bugs applicatifs découverts (corrigés ou tracés)

1. **Token auth sessionStorage/localStorage** (critique, #1575) : le fallback
   polling REST des notifications ne s'activait **jamais** en production depuis
   la PR #1299. Corrigé par `src/services/token-storage.js` (source unique).
2. **Mojibake UTF-8 double-encodé** dans 31 fichiers (admin + vitrine + 2 tests
   PHP) : textes français corrompus à l'écran (« CrÃ©er le poste »). Réparé
   octet-par-octet (C3 83 C2 XY → C3 XY).
3. **F-11 inopérant** (branche golden-payroll) : statut `locked` + colonnes
   `locked_by`/`locked_at` inexistants en base (ni migrations, ni schéma de
   test) — le service de clôture ne pouvait pas s'exécuter. Migration F-11
   ajoutée (résolution dynamique d'enum, pattern geo_auto) + schéma de test.
4. **PayrollClosingService** : audit trail double-encodé (json_encode dans des
   colonnes castées `array`), transitions non atomiques (TOCTOU), exceptions
   non mappées. Corrigé (transactions + mises à jour conditionnelles).
5. **check-test-schema-drift.sh** : le regex ne détecte pas les tables créées
   via `tenantTable()`/`moduleTable()` (noms dynamiques) → rapport de dérive
   inexact. → Issue.
6. **CHANGELOG.md** : encodage mixte latin-1/UTF-8 (mojibake historique) —
   fragile pour toute lecture automatisée. → Issue.
7. **PayrollCalculator (branche golden)** : tous les employés sont payés sur la
   première structure salariale (pas de matching par employé — la colonne
   `salary_structure_id` n'existe que sur `salary_components`). → Issue
   (amélioration F-05/F-20).
