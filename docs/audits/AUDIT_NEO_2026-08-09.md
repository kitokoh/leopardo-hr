## 2. 🔴 Bugs corrigés dans cette session (root causes)

### 2.1 Onboarding Smoke — `.env.example` invalide pour phpdotenv (#1591)
7 valeurs mal formées (générateur #1519 tronquait les expressions PHP) :
`CACHE_PREFIX`, `REDIS_PREFIX`, `MAIL_EHLO_DOMAIN`, `SESSION_COOKIE` (tronqués), `CAMERAS_ACCESS_TOKEN_MAX` (`30 * 24 * 60`), `LOG_DISCORD_USERNAME`/`LOG_SLACK_USERNAME`/`MAIL_SENDMAIL_PATH` (espaces non quotés).
→ `.env.example` reparse 100 % avec `Dotenv::createImmutable()->load()` ; parité 265 clés intacte.

### 2.2 PHPStan strict rouge sur main (#1576)
Baseline obsolète (~3006 erreurs non couvertes). → régénérée localement (`--generate-baseline`), `phpstan analyse` strict : `[OK] No errors`.

### 2.3 PurgeAuditLogsCommandTest — le test tournait AVANT la commande
**Root cause non triviale** : `PendingCommand` (Laravel) exécute la commande **paresseusement dans `__destruct()`**. Le test assignait `$cmd = $this->artisan(...)`, donc les assertions DB (`assertSame(2, count())`) s'exécutaient **avant** la commande → échec systématique en CI, passage local isolé trompeur. Les tests qui chaînent `->assertSuccessful()` en temporaire fonctionnent (destruction immédiate). Fix : `$cmd->run()` explicite. **Pattern à surveiller** : tout test qui assigne un PendingCommand puis vérifie la DB doit appeler `run()`.

### 2.4 PayrollAnomalyService (F-28) — CI rouge
- `having('slip_count', '>', 1)` → alias de SELECT interdit en HAVING PostgreSQL → `havingRaw('COUNT(*) > 1')`.
- Faux positifs `incoherent_slip` sur bulletins **sans lignes** (les tests F-28 en créent sans lignes) → skip si `lines` vide.
→ 5/5 tests verts.

### 2.5 StructuredLoggingMiddlewareTest — 401 au lieu de 200
`/api/v1/metrics` est protégé `auth:super_admin_api` (issue #1466) ; le test anonyme obtenait 401 → le handler d'exception loggait `error()` (Mockery sans expectation) + le middleware loggait le 401. Fix : `Sanctum::actingAs(new SuperAdmin, guard: 'super_admin_api')` → 200.

### 2.6 Trait `use Tests\RefreshTenantDatabase;` dans les classes
Les tests migrés par #1583 utilisaient le trait en référence **relative** dans le corps de classe (`namespace Tests\Feature\Payroll` → résolution `Tests\Feature\Payroll\Tests\...` → fatal). Fix : `use \Tests\RefreshTenantDatabase;` (fully qualified) — 8 fichiers.

### 2.7 Tests payroll migrés — isolation DB (constat d'environnement)
La CI définit `DB_SEARCH_PATH=public,shared_tenants` ; `phpunit.xml` définit `shared_tenants,public` — l'ordre change le schéma cible des migrations et casse `migrate:fresh` en local (la migration 0001 fait `SET search_path TO public` après création du repository). Documenté ; les runs locaux utilisent la config CI.
