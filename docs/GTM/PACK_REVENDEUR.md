## 4. FAQ objections

### "C'est trop cher pour des PME africaines"

> A 3 USD/employe/mois, une PME de 30 employes paie 90 USD/mois. Le gain moyen est de 2 jours/mois d'un charge RH (soit 300-500 USD selon le pays). Le ROI est positif des le premier mois.

### "On a deja un logiciel de paie"

> Leopardo RH n'est pas qu'un logiciel de paie. C'est une plateforme complete : pointage, conges, recrutement, formations, chat IA. L'integration API permet de coexister avec un ERP existant via export/import.

### "Les PME ne veulent pas de SaaS, elles veulent du on-premise"

> Le SaaS elimine les couts serveur et maintenance. Pour les entreprises sensibles, nous proposons un chiffrement des donnees sensibles (IBAN, salaires) et un hebergement dedie sur devis.

### "Et la connexion internet ?"

> L'app mobile et les kiosques fonctionnent hors ligne. Le pointage, les conges et les consultations sont disponibles sans internet. La synchronisation est automatique au retour de la connexion.

### "Comment on migre depuis Excel ?"

> Import CSV/Excel avec mapping automatique des colonnes. L'onboarding guide accompagne le client etape par etape. Temps moyen de migration : 2-4 heures pour une PME de 50 employes.

### "Les donnees sont-elles securisees ?"

> Architecture multi-tenant avec isolation stricte. Chiffrement IBAN/salaires. Backup quotidien automatise. Audit OWASP ZAP integre en CI. Conforme RGPD et loi algerienne 18-07.

## 5. Checklist installation client

### Pre-requis client

- [ ] Liste des employes (Excel/CSV) avec nom, prenom, email, date embauche
- [ ] Parametres paie : convention collective, taux cotisations specifiques
- [ ] Logo entreprise (PNG/SVG)
- [ ] Coordonnees bancaires pour exports virements
- [ ] Pointeuse ZKTeco si applicable (modele, IP reseau)

### Etapes installation (2-4h)

1. [ ] Creer le compte entreprise sur la plateforme
2. [ ] Configurer le pays et les parametres paie
3. [ ] Importer les employes via CSV
4. [ ] Configurer les departements et les roles manager
5. [ ] Configurer les politiques de conges
6. [ ] Connecter la pointeuse ZKTeco (si applicable)
7. [ ] Installer l'app mobile sur 2-3 devices pilotes
8. [ ] Lancer un cycle paie test
9. [ ] Former l'admin RH (30 min visio)
10. [ ] Former les managers (15 min visio)
11. [ ] Activer les notifications push
12. [ ] Verifier l'export bancaire test

### Post-installation (J+7)

- [ ] Appel de suivi avec le client
- [ ] Verifier les premiers pointages reels
- [ ] Verifier le premier cycle paie reel
- [ ] Recueillir le feedback pour ajustements
