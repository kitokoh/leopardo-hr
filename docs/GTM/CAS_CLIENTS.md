# Cas Clients — Leopardo RH

5 mini cas clients types pour la prospection PME Maghreb et Afrique francophone.

---

## 1. Boulangerie Moderne — Alger, DZ

**Secteur** : Alimentation / Distribution
**Effectif** : 45 employes
**Probleme** : Fiches de paie manuelles sur Excel, erreurs frequentes sur les cotisations CNAS/CNR. 2 jours par mois perdus a corriger les bulletins.

**Solution Leopardo** :
- Pointage biometrique → absences automatiques
- Paie DZ avec baremes IRG + CNAS integres
- Bulletins PDF generes en 1 clic

**Resultats** :
- **-80%** temps de traitement paie (de 2j a 4h/mois)
- **0 erreur** cotisation depuis 3 mois
- **+30%** satisfaction employes (bulletins disponibles sur mobile)

> _"Avant, on passait 2 jours chaque mois a corriger les fiches de paie. Maintenant c'est fait en une matinee."_ — Directeur RH

## 2. Cabinet Conseil Juridique — Casablanca, MA

**Secteur** : Services professionnels
**Effectif** : 22 employes
**Probleme** : Gestion des conges sur papier, conflits de planning frequents entre avocats. Aucune visibilite sur les soldes.

**Solution Leopardo** :
- App mobile pour demandes de conge
- Calendrier equipe avec visibilite temps reel
- Politiques de conge configurables (anciennete, grade)

**Resultats** :
- **-60%** conflits de planning
- **100%** demandes traitees sous 24h (vs 3-5 jours avant)
- Soldes consultables a tout moment par les employes

> _"Les avocats peuvent voir les absences de l'equipe avant de planifier leurs audiences."_ — Office Manager

## 3. Societe de Transport — Dakar, SN

**Secteur** : Transport / Logistique
**Effectif** : 120 employes (dont 80 chauffeurs)
**Probleme** : Impossible de suivre les vehicules et les horaires chauffeurs. Carburant non controle, km non traces.

**Solution Leopardo** :
- Suivi GPS vehicules en temps reel (integration Traccar)
- Rapports kilometrage + consommation carburant
- Alertes maintenance automatiques

**Resultats** :
- **-25%** consommation carburant (detection trajets non autorises)
- **+15%** disponibilite vehicules (maintenance preventive)
- Rapport mensuel flotte automatise

> _"On sait maintenant exactement ou sont nos 80 vehicules a tout moment."_ — Directeur Operations

## 4. Clinique Privee — Tunis, TN

**Secteur** : Sante
**Effectif** : 65 employes (medecins, infirmiers, admin)
**Probleme** : Plannings complexes avec rotations jour/nuit. Le pointage se faisait sur feuille, impossible de calculer les heures supplementaires.

**Solution Leopardo** :
- Pointage digital avec calcul automatique heures sup
- Planning par rotation avec gestion equipes
- Dashboard RH avec KPI absenteisme

**Resultats** :
- **-90%** litiges heures supplementaires
- **2h/semaine** gagnees sur la planification
- Taux absenteisme visible en temps reel

> _"Le personnel soignant se concentre sur les patients, pas sur la paperasse RH."_ — DRH

## 5. Startup Tech — Abidjan, CI

**Secteur** : Technologies
**Effectif** : 18 employes (developpeurs, designers, marketing)
**Probleme** : Equipe jeune et distribuee (teletravail partiel). Besoin d'un outil moderne, mobile-first, pour gerer l'admin RH sans lourdeur.

**Solution Leopardo** :
- Onboarding digital (checklist automatique)
- App mobile : conges, bulletins, chat IA pour questions RH
- Dashboard manager avec metriques cles

**Resultats** :
- **Onboarding** nouveau collaborateur en 1 jour (vs 1 semaine)
- **100%** adoption mobile des la premiere semaine
- Questions RH courantes traitees par l'IA (conges, politique teletravail)

> _"L'assistant IA repond aux questions RH basiques, ca m'economise 5h par semaine."_ — CEO
