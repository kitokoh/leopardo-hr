## Notes de production

- **Format** : 1080p horizontal (16:9), sous-titres FR incrustes
- **Musique** : fond corporate doux, libre de droits
- **Voix off** : neutre professionnel, debit modere
- **Captures** : utiliser l'environnement demo avec donnees anonymisees
- **Variantes linguistiques** : les sous-titres EN/AR/TR sont a produire separement
- **Distribution** : YouTube, page /videos de la vitrine, LinkedIn, WhatsApp (version courte 60s)
