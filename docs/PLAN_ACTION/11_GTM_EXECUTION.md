#### Demo standard (20 min)

```
1. Probleme (2 min) — "Combien de temps perdez-vous sur les presences ?"
2. Demo pointage mobile (5 min) — Check-in live + geofence
3. Anomalies (3 min) — Montrer les retards detectes
4. Rapport mensuel (3 min) — Export PDF/CSV
5. Dashboard (3 min) — Vue manager
6. Offre (2 min) — Pilote 14 jours gratuit
7. Questions (2 min)
```
