## 🎨 Technical Branding Guidelines

### Visual Style
- **Aesthetic:** Modern Glass / Premium SaaS.
- **Primary Color:** Indigo/Violet (`#6366f1`).
- **Neutral Palette:** Zinc (`#18181b`).
- **Typography:** Inter (for UI) / JetBrains Mono (for code).

### Diagram Conventions
All Mermaid diagrams should follow these styling conventions for consistency:
- Top-down (`TD`) for hierarchies.
- Left-to-right (`LR`) for sequential workflows.
- Use `subgraph` to group logical layers (Persistence, Application, Client).
