# Platform Admin Documentation

Guides and references for Super Admins managing the Leopardo RH SaaS platform.

## 🔑 Key Responsibilities
- Tenant provisioning and lifecycle management.
- Subscription plan configuration.
- Global security monitoring.
- Platform-wide health checks.

## 🛠 Tools
- **Platform API:** `/api/v1/platform/*`
- **Admin Dashboard:** Located in the `/admin-dashboard` directory.
