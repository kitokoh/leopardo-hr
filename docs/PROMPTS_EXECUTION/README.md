# Prompts d'execution

Ce dossier regroupe les filieres de prompts utilisees pour orchestrer la production sur le projet.

## Structure

- `v3/` : filiere MVP active, a privilegier pour comprendre la construction du produit
- `v2/` : anciennes filieres conservees en lecture seule
- `patches/` : correctifs, ajustements transverses et index de patches

## Regle

Les prompts de ce dossier sont des artefacts d'execution.
Ils peuvent expliquer pourquoi une decision a ete prise, mais ils ne remplacent pas :

- `../../PILOTAGE.md`
- `../REFERENTIEL_PRODUIT/`
- `../GESTION_PROJET/`
- ou le code sur `main`
