## Notes

- Secrets used only by `wzieba/Firebase-Distribution-Github-Action` and the
  Render/Firebase/AWS integrations above are scoped to production/staging
  deploy and mobile-distribution workflows; none of the day-to-day PR-gating
  workflows (`tests.yml`'s backend jobs, `architecture-check.yml`,
  `mobile-apps-ci.yml`, `web-ci.yml`) require secrets to run for a
  contributor without deploy access — they only need the repo checked out.
- `docker run` steps that pull third-party images (e.g. `owasp-zap.yml`'s
  `ghcr.io/zaproxy/zaproxy:stable`, `codeql.yml`'s pinned `semgrep/semgrep`
  digest) do not need registry secrets; both images are public.
- This table is generated by inspection, not by a script. If it drifts from
  `.github/workflows/**`, treat the workflow files as ground truth and update
  this document, not the other way around.
