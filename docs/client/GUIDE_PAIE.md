# Guide paie / comptable (squelette — F-25)

## 1. Avant la clôture
- Vérifier : employés actifs, structures salariales, contrats à jour, absences approuvées, pointages validés.
- Consulter le **rapport d'anomalies** (F-28) : doublons, incohérences, variances.

## 2. Clôture mensuelle
1. Préparer le run (période, pays DZ).
2. Calculer → vérifier les totaux (brut, retenues, net) vs mois précédent.
3. Valider (2 étapes : RH puis comptable) → verrouiller (F-11).
4. Diffuser les bulletins (PDF, archivage Cabinet).

## 3. Exports
- Journal de paie (CSV), déclaration CNAS (CSV), virement (CCP/CPA/BNA), attestation de salaire.

## 4. Audit
- Toute modification post-clôture est tracée (audit trail — F-11) ; exports rejouables.

## 5. Fin de contrat
- Solde de tout compte, certificat de travail, préavis (F-08).
