# Guide RH (squelette — F-25)

## Employés
Créer un employé (matricule, contrat, structure salariale) ; cycle de vie jusqu'à la fin de contrat (F-08).

## Congés
- Demande → approbation ; solde consultable ; acquisition 2,5 j/mois (politique).
- Impact paie : congés payés compensés (indemnité), sans solde retenus (F-07).

## Pointage
- Mobile (hors-ligne), kiosk biométrique ; corrections approuvées ; écarts signalés avant clôture (F-20).

## Rapports
Présence mensuelle, heures sup, absences — alimentent la paie (F-20).
