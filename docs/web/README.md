# Web Applications Documentation

Documentation for the Leopardo RH web ecosystem, including the Manager Dashboard and the Public Vitrine.

## 🖥 Manager Dashboard (Next.js)
The central cockpit for HR administrators and business owners.
- **Path:** `/web`
- **Features:** Employee CRUD, Payroll Approval, Advanced Reporting.

## 🏢 Admin Platform (Vite)
Internal tool for platform operators to manage tenants and billing.
- **Path:** `/admin-dashboard`

Check the root level `front/web/README.md` and `front/admin-dashboard/README.md` for specific setup instructions.
