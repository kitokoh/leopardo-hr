# Validation pointage

Ce sous-dossier contient le referentiel QA du module pointage.

## Fichier principal

- `Leopardo_RH_Pointage_Validation_Finale.pdf` : scenarios de validation finale, criteres PASS/FAIL/BLOCK et checklist de readiness

## Usage

Utiliser ce PDF pour la validation fonctionnelle du module pointage, puis croiser avec :

- le code sur `main`,
- les tests executes,
- et `../../GESTION_PROJET/RUNBOOK_LOCAL_TESTS.md` pour la procedure locale.
