   showcase, kiosk screens).
2. Add new keys to `shared/i18n/locales/fr.json`, then translate EN/AR/TR using the
   Jules guide prompts (`docs/GUIDES/GUIDE_JULES_TRADUCTION_MULTILINGUE.md`).
3. Sync to frontend/mobile targets with the existing `shared/i18n/sync/*.js` scripts
   once a target-specific sync exists for the surface.
4. Keep technical text, routes, API codes, and developer logs out of translation —
   this scanner already excludes them, do not re-flag them manually.
