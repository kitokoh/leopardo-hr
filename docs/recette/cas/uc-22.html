UC-22

Facturation et abonnements (Finance)

Fonctionnel ◻ à exécuter Profil : Finance Module : Plateforme & observabilité

Description / préconditions

Vérifier la consultation des abonnements, des offres et des paiements.

Prérequis : Compte finance plateforme ; permissions BillingView, PlansView, PaymentsView.

Résultat attendu

Les données de facturation sont consultables, les actions hors périmètre sont refusées, les montants sont cohérents.

Étapes de test

  1. Consulter la liste des abonnements.
  2. Ouvrir le détail d'une facture.
  3. Vérifier le registre des paiements et les réconciliations.
  4. Tenter une action réservée à admin et vérifier le refus.
  5. Vérifier les métriques financières.

Votre évaluation humaine

Les notes saisies ici sont enregistrées dans le dépôt (docs/recette/notes-humaines.json) via l'API GitHub : elles sont donc versionnées et visibles par tous. Un jeton personnel GitHub est requis ; il reste stocké uniquement dans votre navigateur.

Configurer mon jeton GitHub

Créez un token sur github.com/settings/tokens avec le scope repo (token classique) ou la permission Contents: Read and write (token fin). Il n'est envoyé qu'à api.github.com et n'est jamais écrit dans le dépôt.
