# Comparatif concurrence — argumentaire honnête

**Issue :** #8445 · **Concept :** `00_CONCEPT.md`

> Deux usages : (1) page « comparatifs » du site, (2) préparation commerciale.
> Règle d'or : **rester factuel** — un comparatif gonflé se retourne contre
> nous. Nos vrais avantages sont suffisants.

## 1. La catégorie en une phrase

Les concurrents excellent chacun dans **une** case (POS, SIRH, ERP).
Leopardo est le seul à couvrir **métier + RH + offline** dans un même
système, pensé pour les entreprises de terrain multi-sites.

## 2. Tableau synthèse

| Critère | **Leopardo** | Toast / Square / Lightspeed (POS) | Odoo / Zoho (ERP) | PayFit / Lucca (SIRH) |
|---|---|---|---|---|
| **Offline-first réel** (service complet sans internet, sync sans doublon) | ✅ natif (bridge Edge local) | ⚠️ mode dégradé limité (pas de sync cuisine/POS complète) | ❌ dépend du serveur | ❌ |
| **Verticales métier prêtes** (restaurant, station-service, retail, santé, éducation, travel, VTC) | ✅ solutions activables à l'onboarding | ✅ restaurant seulement (Toast) | ⚠️ modules génériques à configurer | ❌ |
| **RH + paie + présence intégrés** | ✅ module natif (kiosque biométrique inclus) | ⚠️ planning basique / add-ons | ⚠️ modules séparés | ✅ cœur de métier |
| **Apps terrain complètes** (serveur, cuisine, POS, manager, employé) | ✅ suite native | ✅ sur leur vertical | ❌ | ❌ |
| **Multi-sites + rotations natives** | ✅ affectations et rotations par site | ⚠️ multi-établissements, pas de rotations RH | ⚠️ | ⚠️ |
| **Langues** | **fr / en / ar / tr (RTL)** | en (+ quelques locales) | large (communauté) | fr / quelques langues UE |
| **Onboarding → opérationnel** | minutes (provisioning guidé + checklist) | jours (matériel + paramétrage) | semaines (intégrateur) | jours |
| **Marchés francophones Afrique/Maghreb/Turquie** | cœur de cible (mobile money, DZ/MA/SN/TR) | absents ou limités | présents mais génériques | absents |

Lecture commerciale : face à un POS, on parle **offline + RH intégrée** ;
face à un ERP, on parle **temps de démarrage + métier prêt à l'emploi** ;
face à un SIRH, on parle **opérations terrain (caisse, cuisine, stock)**.

## 3. Où les concurrents sont meilleurs (à assumer)

- **Notoriété et écosystème** : Toast/Square ont des années de présence,
  app stores, intégrations tierces. → Réponse : démo offline décisive,
  onboarding en minutes, proximité marché.
- **Profondeur comptable/fiscale pays par pays** : Odoo a une longueur
  d'avance sur certaines localisations. → Réponse : notre cible veut
  d'abord **faire tourner** l'entreprise ; la compta suit le référentiel.
- **Conformité paie UE** : PayFit/Lucca dominent la paie française. →
  Réponse : on ne se positionne pas sur ce créneau ; nos marchés d'abord.

## 4. Objections et réponses

| Objection | Réponse |
|---|---|
| « Square fait aussi du offline. » | Demandez le test complet : commande serveur → ticket cuisine → encaissement → resync **sans doublon**. C'est exactement notre démo 2 minutes. |
| « Odoo fait tout, et c'est open source. » | Tout, à condition de le configurer. Chez nous, un restaurateur est opérationnel le jour même — restaurant, employés, plats, caisse, cuisine. |
| « Vous êtes jeunes. » | C'est pour ça que la démo est hors-ligne : on montre, on ne promet pas. Et votre donnée reste chez vous (nœud local). |
| « J'ai déjà un POS. » | Gardez-le. Commencez par RH/planning/rotations — puis comparez le jour où internet tombe. |

## 5. Positionnement prix (cadre)

- **Entrée** : espace gratuit pour démarrer (onboarding, équipe, base métier).
- **Croissance** : par site, apps métier incluses (serveur/cuisine/POS).
- **Multi-sites** : palier groupe, rotations et consolidation incluses.
- Jamais de coût caché matériel : le nœud Edge tourne sur une machine
  standard ; le kiosque biométrique est optionnel.

## 6. À maintenir

Ce comparatif est vivant : chaque release concurrente notable (offline,
verticales, langues) déclenche une revue. Propriétaire : GOTO_MARKET.
