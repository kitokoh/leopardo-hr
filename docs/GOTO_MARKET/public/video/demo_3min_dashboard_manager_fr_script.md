# Script Demo 3 Minutes — Dashboard Manager

## Usage

Video demo dashboard manager pour YouTube, LinkedIn et demo commerciale.

## Slide 1 — Accroche

Vous etes manager. Vous gerez une equipe de 10, 50 ou 200 personnes.

Chaque matin, vous avez besoin de savoir : qui est present, qui est absent, qui arrive en retard.

Chaque mois, vous devez valider des demandes de conge, suivre les formations et approuver des notes de frais.

## Slide 2 — Le probleme

Aujourd'hui, ces informations sont dispersees : un fichier Excel pour les pointages, un email pour les conges, un tableau WhatsApp pour les plannings.

Vous perdez du temps a consolider. Et quand la direction demande un rapport, vous passez 2 heures a le produire.

## Slide 3 — Le dashboard Leopardo RH

*(Ecran : Dashboard admin → Vue principale)*

A l'ouverture, vous voyez immediatement :
- **KPI du jour** : employes presents, absents, en retard
- **Alertes** : anomalies de pointage, demandes en attente
- **Graphiques** : tendances presences/absences sur 30 jours

Tout est en temps reel. Pas de consolidation manuelle.

## Slide 4 — Gestion des conges

*(Ecran : Dashboard → Conges → Calendrier equipe)*

1. Un employe soumet une demande de conge depuis l'app mobile
2. Vous recevez une notification en temps reel (SSE + push)
3. Vous visualisez le calendrier equipe pour verifier les chevauchements
4. Vous approuvez ou refusez en 1 clic
5. Le solde de conge est automatiquement ajuste

## Slide 5 — Recrutement pipeline

*(Ecran : Dashboard → Recrutement → Vue kanban)*

Gerez vos postes ouverts en mode kanban :
- **Candidature recue** → **Entretien** → **Offre** → **Embauche**
- Chaque candidat porte un historique : CV, notes d'entretien, evaluations

Fini les spreadsheets de suivi candidatures.

## Slide 6 — Exports et rapports

*(Ecran : Dashboard → Exports)*

Generez en 1 clic :
- Rapport de pointage mensuel (PDF/CSV)
- Rapport absences par departement
- Export paie pour la comptabilite
- Attestations de travail

## Slide 7 — Intelligence artificielle

*(Ecran : Dashboard → Chat IA)*

Posez des questions en langage naturel :
- "Qui a le plus d'heures supplementaires ce mois ?"
- "Quels postes sont ouverts depuis plus de 30 jours ?"
- "Prevision de turnover pour le trimestre prochain"

Leo AI analyse vos donnees RH et vous donne des reponses instantanees.
