# Case Studies — Leopardo RH

## Template pour chaque etude de cas

Chaque etude de cas doit suivre le format ci-dessous (fichier Markdown dans ce dossier).

### Structure

```markdown
# [Nom entreprise] — [Secteur]

## Profil client
- **Secteur** : [ex: BTP, Agroalimentaire, Services]
- **Taille** : [nombre d'employes]
- **Pays** : [DZ, MA, FR, TN, SN, CI]
- **Plan** : [Starter, Business, Enterprise]

## Problematique
[2-3 phrases decrivant le probleme avant Leopardo RH]

## Solution deployee
[Modules utilises, configuration, delai de deploiement]

## Resultats
- **Temps gagne** : [ex: 40% de reduction du temps admin]
- **Conformite** : [ex: declarations CNAS automatisees]
- **ROI** : [ex: amortissement en 3 mois]

## Citation client
> "[Verbatim du client]"
> — [Prenom Nom], [Poste], [Entreprise]
```

## Etudes de cas prevues

## Processus de creation

1. **Interviewer le client** (30-45 min) — utiliser le guide d'entretien dans `03_PLAYBOOK_VENTE.md`
2. **Rediger le brouillon** — suivre le template ci-dessus
3. **Valider avec le client** — obtenir l'accord pour publier
4. **Publier** — ajouter a la page web `/case-studies` et aux supports commerciaux
