# Company OS Thesis

## Notre Thèse Fondamentale

**Leopardo HR n'est PAS :**
- ❌ Un logiciel RH traditionnel
- ❌ Un ERP allégé
- ❌ Un outil de pointage amélioré

**Leopardo HR EST :**
- ✅ **Le Mobile-First Company OS** pour les PME et équipes terrain

---

## Pourquoi cette distinction est critique

### Le piège du "Logiciel RH"

Quand vous dites "logiciel RH", vos prospects entendent :

| Perception | Réalité Leopardo |
|------------|------------------|
| Réservé aux départements RH | Utilisé par TOUS les employés quotidiennement |
| Fonctionnalités complexes | Interface simple comme WhatsApp |
| Usage hebdomadaire/mensuel | Usage quotidien (pointage, notifications, tâches) |
| Desktop-first | 100% mobile |
| Coût élevé (licence + formation) | Abordable, zéro formation |
| Silo fonctionnel | Plateforme centrale de l'entreprise |

**Conséquence :** Si vous vous positionnez comme "logiciel RH", vous êtes comparé à BambooHR, Zoho People, Payfit. Vous perdez.

### Le piège de "l'ERP"

Quand vous dites "ERP", vos prospects entendent :

| Perception | Réalité Leopardo |
|------------|------------------|
| Projet de 6-12 mois | Onboarding en 48h |
| Consultant obligatoire | Self-service complet |
| Customisation infinie | Workflows prédéfinis best-practices |
| Budget > 50k€ | Abonnement < 500€/mois |
| Équipe IT dédiée | Zéro compétence technique requise |

**Conséquence :** Si vous vous positionnez comme "ERP", vous effrayez les PME. Elles fuient.

### Le piège de "l'outil de pointage"

Quand vous dites "outil de pointage", vos prospects entendent :

| Perception | Réalité Leopardo |
|------------|------------------|
| Une seule fonctionnalité | Suite complète (paie, workflow, docs, perf) |
| Utilité marginale | Système nerveux central de l'entreprise |
| Commodité interchangeable | Plateforme sticky (switching cost élevé) |
| Prix bas (5-10€/mois) | Valeur élevée (100-1000€/mois justifiés) |

**Conséquence :** Si vous vous positionnez comme "outil de pointage", vous entrez dans une guerre de prix. Vous ne gagnez pas.

## La Thèse Company OS

### Définition

Un **Company OS (Système d'Exploitation d'Entreprise)** est :

> **La couche fondamentale sur laquelle toute l'entreprise fonctionne.**
> 
> Comme iOS ou Android sont l'OS d'un smartphone, Leopardo est l'OS d'une PME.

### Caractéristiques d'un Company OS

| Caractéristique | Comment Leopardo l'incarne |
|-----------------|----------------------------|
| **Centralité** | Toutes les opérations critiques passent par Leopardo |
| **Ubiquité** | Tous les employés l'utilisent quotidiennement |
| **Extensibilité** | Workflows personnalisables, API, intégrations |
| **Stickiness** | Plus vous l'utilisez, plus il devient indispensable |
| **Plateforme** | Base pour des apps tierces (futur marketplace) |
| **Données unifiées** | Single source of truth pour toutes les données entreprise |

### Analogies Puissantes

```
📱 iPhone avant iOS → Téléphone + iPod + Internet communicator
🏢 PME avant Leopardo → Excel + WhatsApp + Papier + SMS

📱 iPhone après iOS → Écosystème unifié, App Store, services intégrés
🏢 PME avec Leopardo → Écosystème unifié, workflows, services intégrés
```

## Les 5 Piliers du Company OS

### 1. Identité & Accès

```
Leopardo = Annuaire unique de l'entreprise
- Profil employé complet
- Rôles et permissions (RBAC)
- Historique d'activité
- Documents d'identité vérifiés
```

### 2. Temps & Présence

```
Leopardo = Vérité temporelle de l'entreprise
- Pointage biométrique géolocalisé
- Plannings et shifts
- Congés et absences
- Heures supplémentaires automatisées
```

### 3. Argent & Paie

```
Leopardo = Moteur financier social de l'entreprise
- Calcul de paie multi-pays conforme
- Primes et variables automatisés
- Intégration mobile money / virement
- Bulletins digitaux
```

### 4. Communication & Workflow

```
Leopardo = Système nerveux de l'entreprise
- Notifications push ciblées
- Annonces et actualités
- Workflows métier (validation, approval)
- Tâches et suivi d'exécution
```

### 5. Performance & Growth

```
Leopardo = Boussole de croissance de l'entreprise
- Objectifs individuels et collectifs
- Évaluations et feedback
- Analytics et tableaux de bord
- Détection de risques (turnover, absentéisme)
```

## Implications Stratégiques

### 1. Pricing Power

Un "outil de pointage" se vend 5€/mois/utilisateur.  
Un "Company OS" se vend 50-100€/mois/entreprise + variables.

**→ Notre pricing doit refléter la valeur plateforme, pas la commodité.**

### 2. Rétention

Un outil mono-fonction a un churn élevé (facile à remplacer).  
Un OS a un churn faible (trop de données, processus, habitudes).

**→ Notre north star metric : le nombre de fonctions utilisées activement.**

### 3. Expansion

Un outil a un plafond de verre (une fois déployé, pas d'upsell).  
Un OS permet l'expansion naturelle (modules additionnels, marketplace).

**→ Notre roadmap doit prioriser les modules qui renforcent la centralité.**

### 4. Marketing

On ne vend pas un OS avec des features. On le vend avec une **vision**.

**→ Notre messaging doit être aspirational, pas feature-led.**
