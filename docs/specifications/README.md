# Spécifications Fonctionnelles et Techniques

Conformément aux règles du projet (`AGENTS.md`), ce dossier contient les spécifications de tous les nouveaux modules de Leopardo RH.

**Règle d'Or :**
1. Un agent doit toujours rédiger et faire valider la spécification d'un module ICI avant de générer des tickets GitHub (Issues).
2. Ce dossier garantit que l'architecture et les règles métier sont comprises avant d'écrire la moindre ligne de code.

## Format Recommandé

- `Nom du Module` (ex: ATS / Recrutement)
- `Base de données` : Tables à créer ou modifier.
- `API` : Routes backend à exposer.
- `Vues Front/Mobile` : Écrans nécessaires.
- `Règles Métier (RBAC)` : Qui a accès à quoi.
