Production notes

Le parcours cabinet s'appuie sur le module Accounting (api/app/Modules/Accounting), PAS sur le module Cabinet (api/app/Modules/Cabinet) : ce dernier est un placard personnel de documents (dossiers, upload, partage par token), pas un outil d'expertise comptable. Accounting : AccountingDocument (DocumentType invoice, proforma, quote, credit_note, delivery_note, receipt, purchase_invoice, purchase_credit_note ; DocumentStatus draft, sent, partially_paid, paid, cancelled, overdue), AccountingJournal (JournalType sale, purchase, bank, cash, payroll, misc, opening), lettrage (LetteringService, erreurs LETTERING_UNBALANCED / LETTERING_INVALID / LETTERING_ALREADY_USED), export FEC (norme DGFiP, 13 colonnes CSV UTF-8, nom de fichier SIRENFECAAAAMMJJ pour un tenant français), AccountingFiscalYear et AccountingClosedPeriod (cloture d'exercice, periode verrouillee), partage de document par token (DocumentShareService, TTL par defaut 14 jours, borne 1 a 365 jours). Le rôle 'comptable' existe dans le RBAC (manager_rôle). Ne pas afficher de montants reels ni de taux : ils dépendent du pays et de l'année. Le FEC est un format français : préciser le pays si le film est diffusé hors France. FR
