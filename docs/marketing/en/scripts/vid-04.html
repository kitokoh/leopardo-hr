How Leopardo replaces Excel, WhatsApp and paper (3-minute explainer)

🎬 Solution overview16:9 ⏱ 3 min 🎯 Evaluating executives, product page, async demo

Film objective

Answer objections before the sales call: migration, security, multi-country, price. Screen-capture format with commentary.

Hook (first 3 seconds)

« We are not asking you to change how you work. We are asking you to stop documenting it three times. »

Breakdown

TimeVoice-over Shot / imageOn-screen text
0:00-0:15 We are not asking you to change how you work. We are asking you to stop documenting it three times. Trois copies du même document sur trois outils. FR The problem is not the tool. It is triple entry.
0:15-0:50 First step: the reference data. One employee, one record, one contract, documents. Entered once, used everywhere. Capture : création d'un employé, puis le même employé visible dans paie, pointage et congés. FR Enter once.
0:50-1:30 Second step: the field. Attendance comes up from mobile or the kiosk. If the network drops, the terminal keeps working and resyncs when the link returns. Capture kiosque, coupure simulée, file hors-ligne, resynchronisation. FR The field does not stop when the network stops.
1:30-2:10 Third step: payroll. The country's rules apply, attendance and leave variables flow in, the payslip is generated and archived. Capture simulation de paie, puis bulletin PDF. FR 21 countries of payroll rules in pilot.
2:10-2:40 Fourth step: openness. 994 documented API endpoints, webhooks, and business packs you activate according to your sector. Capture documentation OpenAPI, puis grille de packs. FR 994 endpoints - activatable packs
2:40-3:00 Multi-tenant isolation, RBAC, audit log. Your data stays yours, in the cloud or self-hosted. Schéma d'isolation, écran de rôles. FR Cloud or self-hosted.
