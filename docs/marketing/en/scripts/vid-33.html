Film objective

Show the Delivery module (BC-26): routes and stops, proof of delivery (POD), recipient tracking, and cash-on-delivery (COD) settlements reconciled with accounting.

Production notes

Module Delivery (BC-26, api/app/Modules/Delivery) : cycle de vie verrouille par DeliveryStateMachine (created -> assigned -> picked_up -> out_for_delivery -> arrived -> delivered | failed -> returned | cancelled ; etats terminaux non rouvrables). Statuts d'arret : pending, en_route, arrived, delivered, failed, skipped. Preuve de livraison = documents ; encaissements COD = comptabilite. Ne pas afficher de delai ni de taux de reussite chiffre : le produit ne les invente pas. FR
