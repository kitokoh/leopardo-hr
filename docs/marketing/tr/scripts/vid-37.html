Yapim notlari

Module Fundraising (api/app/Modules/Fundraising, spec docs/specifications/SOLUTION_FUNDRAISING.md). Cagnotte : Fundraiser (slug public stable, categorie medical/education/emergency/community/project/other, objectif, montants suggeres, fenetre de collecte starts_at..ends_at, statut draft/active/paused/completed/closed/cancelled). Contributions : ContributionMethod (card, mobile_money, bank_transfer, cash), ContributionStatus (pending, completed, failed, refunded) ; passerelles Stripe (carte), CinetPay / PayDunya / Pvit (mobile money), et confirmation manuelle des especes / virements par le responsable. Reversements : FundraisingPayout (method mobile_money ou bank_transfer, statut requested/processing/paid/failed/cancelled). Reglages : methodes activees, montants min/max, anonymat, messages, affichage des soutiens. IMPORTANT : le recu fiscal automatique n'existe pas encore (mentionne 'recu phase 2' dans le code) : ne jamais promettre que les recus partent seuls. Ne pas afficher de montant collecte reel ni de nombre de donateurs : donnees de demonstration uniquement. FR
