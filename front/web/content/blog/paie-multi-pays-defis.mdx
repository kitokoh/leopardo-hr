# Paie Multi-Pays: Relever les Defis de la Conformite

## Le Defi de la Paie Internationale

Gerer la paie dans plusieurs pays est un defi majeur pour les entreprises en croissance. Chaque pays a ses propres:
- Baremes fiscaux (tranches d'imposition)
- Cotisations sociales (taux employeur/employe)
- Conventions collectives
- Formats de bulletin de paie

## Les Pays Supportes par Leopardo RH

### France
- URSSAF, retraite complementaire, CSG/CRDS
- Prelevement a la source
- DSN mensuelle

### Algerie
- CNAS, CNR
- IRG progressif
- Format CCP pour virements

### Turquie
- SGK, gelir vergisi
- Prime/AGI deductions
- Formats bancaires locaux

### Senegal, Maroc, Tunisie
- Cotisations CNSS/CNPS
- Baremes fiscaux locaux
- Exports comptables adaptes

## Automatisation avec Leopardo RH

Le moteur de paie de Leopardo RH:
1. **Detecte automatiquement** le pays de l'employe
2. **Applique les baremes** fiscaux et sociaux en vigueur
3. **Genere le bulletin** au format PDF conforme
4. **Exporte** les virements (SEPA, CCP, CSV)

## Bonnes Pratiques

- Mettez a jour les baremes a chaque changement legislatif
- Conservez les bulletins pendant 5 ans minimum
- Effectuez des audits de paie trimestriels
- Formez vos equipes RH aux specificites locales
