### Règles CI implémentées (`CedeaoPayrollRules`)

- **ITSAS** (CGI CI art. 116-120) : barème annuel 5 tranches (0 % / 2 % / 21 % / 24,5 % / 29 %) remplaçant les 5 tranches génériques du placeholder ; assiette = brut − CNSS salariale − **abattement frais pro 20 % non plafonné**.
- **CN (Contribution Nationale)** : `max(0, brut − 50 000) × 1,5 %` — calculée séparément (assise sur le brut) via `calculateBracketTax()` ; nouvelle méthode d'interface `flatPayrollTaxLabel()` pour afficher « Contribution Nationale (CN) » sur le bulletin (les autres pays gardent « Taxe de minimum fiscal »).
- **CNSS CI** : retraite 3,2 % salarié + 4,5 % patronal, famille 5,75 % patronal (plafond **1 647 315 XOF/mois**), AT 2,0 % patronal non plafonné — codes `CNSS_CI_RET_EMP/PAT`, `CNSS_CI_FAM_PAT`, `CNSS_CI_AT_PAT`. L'ancien agrégat placeholder 16,4 % est remplacé par le total légal 12,25 % (avec plafonnement partiel).
- **13ème mois** : `thirteenthMonthMandatory() = true` (conventions de branche OHADA-CI, versé en décembre).
- **Préavis** (Code du travail CI art. 18) : 30/60/90 j selon ancienneté (matrice complète catégorie × ancienneté documentée dans CI_COMPLIANCE.md §6 — le moteur ne transmet pas la catégorie).
- **HS** (art. 21) : paliers +15 % / +35 % / +50 %.
- **Jours fériés fixes CI** documentés dans `publicHolidaysSource()`.
- `confidenceLevel()` CI → `pilot` ; autres membres UEMOA (ML/BF/BJ/TG/NE) **inchangés** (placeholder).
